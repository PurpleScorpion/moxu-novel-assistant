# 墨序 小说辅助系统

面向小说作者的本地桌面写作软件。启动后创建或选择书籍，在书内编写和保存章节，通过顶部工具栏插入人物、事件、积分与自定义属性面板，同时管理设定、关系、资源收支和故事时间轴。

- 软件名称：小说辅助系统
- 项目品牌：墨序（Moxu）
- 建议 Git 仓库名：`moxu-novel-assistant`
- 项目位置：`D:\work_space\py\moxu-novel-assistant`
- 技术方案：C++、Qt Widgets、SQLite
- 首期平台：Windows 11 x64
- 当前版本：Windows 桌面写作预览版 0.4

解压完整的便携 ZIP，双击 `Moxu.exe`。首次启动选择小说保存目录，默认使用程序旁的“书籍”文件夹。之后可在书架修改。打开书籍后，左侧可切换书籍概览、人物档案、人物关系和事件账本。右侧直接编辑书名、题材、简介和人物自定义属性。点击“进入专注写作”编写章节，顶部的“返回资料工作区”可切回。正文自动保存，在写作工具栏可以登记资源收支、插入人物属性面板、备份和导出。

### 写作 Skill 与大纲

在资料侧栏打开「全局 Skill」或「本书 Skill」，为一条写作要求起名并填写内容。例如，全局规则可以约定“用动作表现情绪”，本书规则可以约定“师父对徒弟一律以姓氏相称”。全局规则保存在当前 Windows 用户的墨序数据目录 `skills.sqlite` 中。本书规则随 `.moxu` 文件保存和备份。

在任一 Skill 页面点「导入 SKILL.md…」，选择文件，并在同一窗口的「导入到」下拉框选择全局或本书。导入会新增一条规则，即使同名也会保留已有条目。回到「AI 写作」即可勾选它。

选中要分享的规则，点「导出 SKILL.md…」并选择保存位置。导出的文件包含当前规则的名称、描述和 Markdown 正文。墨序创建的中文标题会随文件保存，再次导入时可还原。支持 UTF-8 的 YAML 文件头和普通 Markdown。交换范围为单个文件；其他作者可另外取得其中引用的附件。[SKILL.md 格式说明](https://agentskills.io/specification)

「创作大纲」用于管理剧情。每条大纲可属于全书或某一章，例如把“山门初遇，隐去师父身份”关联到第一章。大纲和 Skill 均支持直接编辑、保存和删除。

进入专注写作，选中一段文字并点击「AI 写作」即可润色。直接从光标处进入则默认续写，带入光标前最多 3000 个字符。勾选这次要用的 Skill 和大纲，修改任务与正文上下文，在「发送预览」中核对内容。填写服务商的 API 密钥及模型，点「发送给 AI」。结果可编辑，点「采纳」后插入光标处或替换原选区。云服务可能按账户用量计费。密钥只保留在本次运行的内存中。

可选 DeepSeek、智谱 GLM 的通用对话接口，或已在本机启动的兼容服务。本机模式填写模型标识和监听端口，使用 `http://127.0.0.1:<端口>/v1/chat/completions`。服务商密钥可通过官方平台申请。[DeepSeek 接口文档](https://api-docs.deepseek.com/) · [智谱接口文档](https://docs.bigmodel.cn/cn/api/introduction)

预览版的资源以整数记录，首次登记前按零计算。属性面板插入时读取当前人物资料和截至本章的余额，之后保留为正文。正文版本可恢复。本版暂以章节顺序作为故事顺序，历史人物属性、独立剧情节点和内置模型插件中心仍在规划中。

### 开发与构建

开发构建使用 Qt 6.8.3（含 Qt Translations 中文语言包）、MinGW 13.1、CMake 和 Ninja。CMake 首次配置时获取并校验 yaml-cpp 0.8.0，静态链接到程序。中文控件翻译嵌入可执行文件。在开发机将配套 Qt、MinGW 和 Ninja 的 bin 目录加入 PATH 后执行：

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/mingw_64
cmake --build build
ctest --test-dir build --output-on-failure
./packaging/portable.ps1 -Executable build/Moxu.exe -Destination dist/Moxu-preview
```

完整方案见 [小说辅助系统设计书](docs/设计书.md)，包含书籍欢迎页、正文编辑器、可自定义的插入模板、数据与历史模型、备份恢复和分阶段验收标准。

中文错别字检查与离线模型插件的规划见 [AI写作辅助可行性调查](docs/AI写作辅助可行性调查.md)。当前自动化测试使用本机模拟接口验证请求内容和正文采纳流程。

本项目以离线使用为默认方式。Windows 便携包携带桌面程序的运行依赖。

插件安装前须展示最低配置、推荐配置与本机检测结果；硬性要求不满足时阻止安装。运行时重检可用内存并限制AI资源占用，优先保护正文保存。具体最低配置须按插件版本实测后公布。
