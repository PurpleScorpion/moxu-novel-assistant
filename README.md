# 墨序 小说辅助系统

面向小说作者的本地桌面辅助软件，用于管理人物、设定、关系、资源收支和故事时间轴，帮助作者追溯数据来源并发现前后矛盾。

- 软件名称：小说辅助系统
- 项目品牌：墨序（Moxu）
- 建议 Git 仓库名：`moxu-novel-assistant`
- 项目位置：`D:\work_space\py\moxu-novel-assistant`
- 技术方案：C++、Qt Widgets、SQLite
- 首期平台：Windows 11 x64
- 当前阶段：设计阶段，尚未实现可运行程序

完整方案见 [小说辅助系统设计书](docs/设计书.md)，包含产品范围、交互流程、数据与历史模型、桌面技术选型、备份恢复和分阶段验收标准。

本项目以离线使用为默认方式。计划提供随包携带依赖的桌面发行包，使作者无需自行配置开发环境。实际体积和免安装运行能力在技术原型阶段验证。
