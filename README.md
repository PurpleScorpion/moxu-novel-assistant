# 墨序 小说辅助系统

面向小说作者的本地桌面写作软件。启动后创建或选择书籍，在书内编写和保存章节，通过顶部工具栏插入人物、事件、积分与自定义属性面板，同时管理设定、关系、资源收支和故事时间轴。

- 软件名称：小说辅助系统
- 项目品牌：墨序（Moxu）
- 建议 Git 仓库名：`moxu-novel-assistant`
- 项目位置：`D:\work_space\py\moxu-novel-assistant`
- 技术方案：C++、Qt Widgets、SQLite
- 首期平台：Windows 11 x64
- 当前阶段：设计阶段，尚未实现可运行程序

完整方案见 [小说辅助系统设计书](docs/设计书.md)，包含书籍欢迎页、正文编辑器、可自定义的插入模板、数据与历史模型、备份恢复和分阶段验收标准。

中文错别字检查与上下文润色方案见 [AI写作辅助可行性调查](docs/AI写作辅助可行性调查.md)。AI插件默认不安装；作者需要时在软件“插件中心”点击安装，由软件自动下载、校验并启用模型和依赖，之后可离线使用。联网服务作为可选替代路线，默认不启用。候选模型尚未完成小说样本和本机性能测试。

本项目以离线使用为默认方式。计划提供随包携带依赖的桌面发行包，使作者无需自行配置开发环境。软件主体和可选AI模型分别标注体积，实际性能与免安装运行能力在技术原型阶段验证。
