# 墨序 小说辅助系统

面向小说作者的本地桌面写作软件。启动后创建或选择书籍，在书内编写和保存章节，通过顶部工具栏插入人物、事件、积分与自定义属性面板，同时管理设定、关系、资源收支和故事时间轴。

- 软件名称：小说辅助系统
- 项目品牌：墨序（Moxu）
- 建议 Git 仓库名：`moxu-novel-assistant`
- 项目位置：`D:\work_space\py\moxu-novel-assistant`
- 技术方案：C++、Qt Widgets、SQLite
- 首期平台：Windows 11 x64
- 当前版本：Windows 桌面写作预览版 0.7

解压完整的便携 ZIP，双击 `Moxu.exe`。首次启动选择小说保存目录，默认使用程序旁的“书籍”文件夹。之后可在书架修改。打开书籍后，左侧可切换书籍概览、人物档案、人物关系和事件账本。右侧直接编辑书名、题材、简介和人物自定义属性。点击“进入专注写作”编写章节，顶部的“返回资料工作区”可切回。正文自动保存，在写作工具栏可以登记资源收支、插入人物属性面板、备份和导出。

书架的新建、打开和目录选择均在页内完成。新书默认以书名命名文件；遇到同名文件，可以保留书名，直接修改保存路径中的文件名或选择其他目录。

专注写作的工具在正文右侧展开。「属性面板」在同一栏选择人物和模板，修改预览后插入原光标或选区。「记录事件」同时展示收支前后的余额，可选仅记账或同时插入正文。校验提示显示在表单内，输入内容会保留。点击「收起」可放弃本次操作，回到原来的写作位置。历史恢复、模板、校对、备份和文本导出也在页内完成。

### 写作 Skill 与大纲

在资料侧栏打开「全局 Skill」或「本书 Skill」，为一条写作要求起名并填写内容。例如，全局规则可以约定“用动作表现情绪”，本书规则可以约定“师父对徒弟一律以姓氏相称”。全局规则保存在当前 Windows 用户的墨序数据目录 `skills.sqlite` 中。本书规则随 `.moxu` 文件保存和备份。

在任一 Skill 页面点「导入 SKILL.md…」，从页内文件树选择文件或粘贴路径，在「导入到」选择全局或本书，再点「确认导入」。错误会显示在当前表单，可以直接修正后重试。同名导入会新增一条规则。回到「AI 写作」即可勾选它。

选中规则，点「导出 SKILL.md…」并在原页选择保存位置。目标已存在时，可改名或勾选覆盖；更改路径会重置覆盖选择。删除 Skill 或大纲条目也在资料页内确认或取消。导出的文件包含当前规则的名称、描述和 Markdown 正文，墨序创建的中文标题可在再次导入时还原。支持 UTF-8 的 YAML 文件头和普通 Markdown。交换范围为单个文件；引用的附件需另行分享。[SKILL.md 格式说明](https://agentskills.io/specification)

「创作大纲」用于管理剧情。每条大纲可属于全书或某一章，例如把“山门初遇，隐去师父身份”关联到第一章。大纲和 Skill 均支持直接编辑、保存和删除。

专注写作的章节目录显示序号，正文上方显示当前章及总章数。双击章节或点「改章名」即可就地修改标题。正文、历史和大纲继续关联到原章节。

### 设置和使用 AI

1. 在书架或「AI 写作」中打开「AI 配置」。选择 DeepSeek、智谱 GLM（国内）、Z.AI GLM（国际）、本机兼容服务，或点「新增站点」填写兼容接口的基础地址。可直接使用预设模型，也可点「从站点读取模型」。支持模型列表接口的站点会自动补全列表，也可按每行一个标识编辑，保存后从下拉列表选择。实际调用权限取决于服务商账户。
2. 在本站点输入 API 密钥。默认仅在本次运行中使用，勾选「在此电脑记住密钥」后保存到当前用户的 Windows 凭据管理器。模型和站点设置对所有书籍可用。可以取消勾选再保存，移除持久保存的密钥。
3. 在专注写作中，选中文字后打开「AI 写作」可润色，直接打开则默认续写，带入光标前最多 3000 个字符。选择站点与模型后可点「测试连接」，只发送一条简短测试消息。云服务可能按用量计费。
4. 需要约束文风时勾选写作 Skill，需要剧情参考时勾选大纲，也可以都不选。在「发送预览」核对资料和上下文后发送。可查看生成进度或取消请求。编辑候选正文，点「采纳」写回原光标或选区。

国内智谱和国际 Z.AI 使用独立站点。自定义接口支持 HTTPS，本机服务也可使用 `http://127.0.0.1:8080/v1` 等回环地址。[DeepSeek 接口文档](https://api-docs.deepseek.com/) · [智谱接口文档](https://docs.bigmodel.cn/cn/api/introduction) · [Z.AI 接口文档](https://docs.z.ai/guides/overview/quick-start)

预览版的资源以整数记录，首次登记前按零计算。属性面板插入时读取当前人物资料和截至本章的余额，之后保留为正文。正文版本可恢复。本版暂以章节顺序作为故事顺序，历史人物属性、独立剧情节点和内置模型插件中心仍在规划中。

### 开发与构建

开发构建使用 Qt 6.8.3（含 Qt Translations 中文语言包）、MinGW 13.1、CMake 和 Ninja。CMake 首次配置时获取并校验 yaml-cpp 0.8.0，静态链接到程序。中文控件翻译嵌入可执行文件。在开发机将配套 Qt、MinGW 和 Ninja 的 bin 目录加入 PATH 后执行：

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/mingw_64
cmake --build build
ctest --test-dir build --output-on-failure
./packaging/portable.ps1 -Executable build/Moxu.exe -Destination dist/Moxu-preview
```

完整方案见 [小说辅助系统设计书](docs/设计书.md)，包含书籍欢迎页、正文编辑器、可自定义的插入模板、数据与历史模型、备份恢复和分阶段验收标准。

中文错别字检查与离线模型插件的规划见 [AI写作辅助可行性调查](docs/AI写作辅助可行性调查.md)。当前自动化测试使用本机模拟接口验证请求内容和正文采纳流程。

本项目以离线使用为默认方式。Windows 便携包携带桌面程序的运行依赖。

插件安装前须展示最低配置、推荐配置与本机检测结果；硬性要求不满足时阻止安装。运行时重检可用内存并限制AI资源占用，优先保护正文保存。具体最低配置须按插件版本实测后公布。
