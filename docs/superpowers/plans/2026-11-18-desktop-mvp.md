# 桌面写作预览版实施与验证

依据《设计书》第四、七至十二节，第一批实现每书一个数据库、章节编辑、人物、资源流水和输出模板，用实际便携包验证发行方式。预览文件格式为 1。后续演进要在书籍副本上验证迁移，升级前保留独立备份。

| 实施顺序 | 检查点 |
| --- | --- |
| 创建与打开书籍、章节编辑与版本保存 | GUI 进入书籍、输入中文、换章、自动保存后从 SQLite 读取正文 |
| 资源事件、历史顺序、正文联合提交 | 跨章节回放余额，拒绝导致后续透支的操作，重开后校验 |
| 人物资料、模板、关系图、时间轴 | 在写作页操作工具栏，在当前书内读取关联资料 |
| Windows 便携打包 | 从发行目录加载 Qt 平台插件和 SQLite 驱动，移除开发工具 PATH 后启动并实际读写 |
| 后续完整版本 | 故事节点及事件修订、属性历史、模板绑定、AI 插件资源保护与外部 API 按设计书验收 |
